## 0. 표기 규칙

| 기호 | 의미 |
|---|---|
| `[ ]` | 입력 필드 또는 버튼 |
| `{ }` | 표시 텍스트 영역 |
| `(var)` | 동적 값 |
| `▶` | 클릭 가능한 액션 |
| `───` | 수평 디바이더 |
| `•` | 카테고리 색상 점 |
| `☐` | 미완료 체크박스 |
| `☑` | 완료 체크박스 |
| `[★]` | 강조 요소 (오늘 날짜 등) |
| `[PRD 확정]` | PRD에 명시된 사항 |
| `[AI 제안안]` | 구현 필요상 추가 정의 |

컨테이너 최대 너비: 800px (중앙 정렬). [PRD 확정] PRD §14-4
