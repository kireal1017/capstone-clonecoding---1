| 항목 | 내용 |
| --- | --- |
| 서비스명 | PlanMate |
| 서비스 유형 | 웹 기반 일정·과제 관리 서비스 |
| 핵심 콘셉트 | 대학생이 과제, 시험, 미팅, 약속, 개인 일정을 캘린더 중심으로 관리할 수 있는 서비스 |

| 주요 목적 | 마감일이 있는 일정과 할 일을 한눈에 확인하고, 우선순위에 따라 효율적으로 관리할 수 있도록 지원 |
| 참고 서비스 | 아이폰 캘린더, Todo List 앱 |

# 2. 서비스 기획 방향

## 핵심 방향

- 메인페이지에서 **월간 캘린더**를 가장 먼저 보여준다.
- 우측 하단에 `+` 형태의 **할 일 등록 버튼**을 배치한다.
- 할 일 등록 버튼을 누르면 **별도 등록 페이지**로 이동한다.
- 메인페이지 아래로 스크롤하면 **오늘 할 일**과 **주간 일정 바**를 확인할 수 있다.
- 완료한 할 일은 삭제하지 않고 **중간줄 + 회색 처리**로 표시한다.
- 완료된 할 일은 **오늘 할 일 목록에서는 최하위로 이동하고 비활성화**한다.
- 알림 기능과 AI 추천 기능은 초기 버전에서는 제외한다.

# 5. 기능 상세 명세

## 5.1 월간 캘린더 보기

| 항목 | 내용 |
| --- | --- |
| 기능 목적 | 사용자가 한 달 전체 일정을 한눈에 확인할 수 있도록 한다. |
| 위치 | 메인페이지 상단 |
| 주요 요소 | 현재 월, 이전 달 버튼, 다음 달 버튼, 날짜 셀, 일정 표시 |
| 표시 방식 | 날짜별 일정 개수를 점, 숫자, 색상 라벨 등으로 표시 |
| 사용자 동작 | 날짜를 클릭하면 해당 날짜의 일정 목록을 확인할 수 있음 |

### 세부 동작

- 메인페이지 진입 시 현재 월의 캘린더가 표시된다.
- 날짜별로 등록된 일정이 있으면 해당 날짜에 표시가 나타난다.
- 일정 카테고리에 따라 색상 점 또는 라벨이 다르게 표시된다.
- 사용자는 이전/다음 달 버튼을 통해 다른 월의 일정을 확인할 수 있다.

# 6. 화면 구성

## 6.1 메인페이지

### 구성 순서

1. 상단 검색 및 프로필 아이콘 바
2. 현재 월, 이전/다음 달 이동 버튼
3. 월간 캘린더
4. 오늘 할 일
5. 주간 일정 바

7. 우측 하단 할 일 등록 버튼

# 7. 사용자 흐름

## 7.1 일정 등록 흐름

1. 사용자가 메인페이지에 접속한다.
2. 월간 캘린더를 확인한다.
3. 우측 하단 `+` 버튼을 클릭한다.
4. 할 일 등록 페이지로 이동한다.
5. 제목, 마감일, 시간, 카테고리, 중요도, 메모를 입력한다.
6. 저장 버튼을 클릭한다.
7. 등록된 일정이 캘린더와 오늘 할 일, 주간 일정에 반영된다.

---

## 7.2 오늘 할 일 완료 흐름

1. 사용자가 메인페이지에서 오늘 할 일 목록을 확인한다.
2. 완료한 일정의 체크박스를 클릭한다.
3. 해당 일정은 중간줄과 회색으로 표시된다.
4. 완료된 일정은 오늘 할 일 목록에서 중간이 적용되고 회색으로 텍스트를 표시하며, 오늘 할 일에서 최하위에 배치된다.
5. 전체 일정 또는 상세보기에서는 완료 상태로 확인할 수 있다.

---

## 7.3 주간 일정 확인 흐름

1. 사용자가 메인페이지 아래로 스크롤한다.
2. 주간 일정 바를 확인한다.
3. 월~일 중 특정 요일을 선택한다.
4. 선택한 요일 아래로 일정 목록이 확장된다.
5. 사용자는 해당 요일의 일정을 확인하거나 상세보기로 이동할 수 있다.

# 8. 우선순위 정렬 기준

## 8.1 오늘 할 일 정렬 기준

| 우선순위 | 기준 |
| --- | --- |
| 1순위 | 마감 시간이 빠른 일정 |
| 2순위 | 중요도 높음 |
| 3순위 | 마감일이 오늘인 일정 |
| 4순위 | 등록 순서 |

## 8.2 중요도 기준

| 중요도 | 의미 |
| --- | --- |
| 높음 | 반드시 오늘 처리해야 하거나 중요한 일정 |
| 보통 | 일반적인 일정 |
| 낮음 | 급하지 않은 일정 |

# 9. 최종 정리

이 서비스의 핵심은 **대학생이 마감일 중심으로 과제와 일정을 관리할 수 있도록 돕는 것**이다.

- 월간 캘린더
- 할 일 등록
- 오늘 할 일
- 주간 일정 바
- 완료 처리
- 카테고리 구분
- 마감 임박 표시
- 일정 수정/삭제
- 검색 및 필터

이를 통해 사용자는 오늘 해야 할 일과 이번 주 일정을 한눈에 확인할 수 있으며, 완료된 일정은 Todo 리스트 방식으로 직관적으로 관리할 수 있다.
